## 1. Princípio

A Série A preserva o DNA visual do NEURAL NEXUS, mas não replica a linguagem da Série B.

**Série A = MAPA / SISTEMA / ORGANIZAÇÃO / VISÃO PANORÂMICA.**  
**Série B = ZOOM / MECANISMO / INVESTIGAÇÃO / IMERSÃO.**

Regra central:

> Consistência de identidade não significa repetição de template.

O sistema compartilhado inclui formato, proporção, hero/header, identificação NEURAL NEXUS, hierarquia tipográfica, footer, assinatura, fontes, safe area e acabamento editorial. A arquitetura interna, metáfora visual, composição e uso cromático devem variar conforme a função pedagógica.

## 2. Linguagem cromática

A Série A utiliza uma linguagem clara, acadêmica e cartográfica.

| Função semântica | Cor | HEX |
|---|---|---|
| Fundo principal | Off-white científico | #F4F7F8 |
| Fundo secundário | Cinza frio | #E7EEF1 |
| Estrutura / hierarquia | Navy profundo | #102A43 |
| Informação principal | Azul neuro | #1677B8 |
| Fluxo / conexão | Cyan | #20B8C8 |
| Função / integração | Teal | #16A085 |
| Destaque / transição | Âmbar | #F2A541 |
| Texto principal | Grafite | #17202A |
| Texto secundário | Slate | #52616B |

### Regra de uso

A paleta é semântica, não decorativa.

- **Navy:** estrutura, organização, anatomia e hierarquia.
- **Azul:** informação neurocientífica principal.
- **Cyan:** fluxo, comunicação, conexão e transição.
- **Teal:** função, integração e regulação.
- **Âmbar:** destaque pontual, exceção, transição ou ponto de atenção.
- **Grafite/Slate:** texto.

Não utilizar todas as cores obrigatoriamente em cada peça.

## 3. Relação com a Série B

A Série B permanece com sua linguagem própria, escura e molecular.

A Série A não deve ser tratada como uma versão clara da Série B.

| Dimensão | Série A | Série B |
|---|---|---|
| Função | Conceito e sistema | Mecanismo e zoom |
| Metáfora | Mapa | Atlas / investigação |
| Fundo | Claro | Escuro |
| Contraste | Editorial | Dramático |
| Navegação | Hierarquia sistêmica | Escala e zoom |
| Composição | Modular / cartográfica | Molecular / imersiva |
| Paleta dominante | Off-white + navy + azul/cyan/teal | Obsidiana + índigo + violeta/magenta |
| Pergunta pedagógica | “Como o sistema se organiza?” | “Como o mecanismo funciona?” |

## 5. Hero da Série A

O hero mantém a estrutura institucional do NEURAL NEXUS, porém sua metáfora deve ser **panorâmica e sistêmica**.

### Direção

- representar território conceitual, não mecanismo molecular;
- priorizar relações, sistemas, estruturas ou mapas;
- evitar aparência de microscopia profunda;
- evitar excesso de elementos decorativos;
- permitir leitura imediata do título e do ID.

A composição do hero deve mudar de acordo com o tema.

## 7. Arquitetura de informação

A Série A não possui um único template obrigatório.

O sistema define uma família de arquétipos:

### A-MASTER-01 — System Overview
Para conceitos que exigem visão geral de componentes e relações.

### A-MASTER-02 — Structure / Function
Para conceitos em que organização estrutural e função precisam ser contrastadas.

### A-MASTER-03 — Process / Flow
Para processos, sequências, ciclos e relações causais ou funcionais.

Novos arquétipos somente devem ser criados quando o conteúdo não puder ser representado adequadamente pelos anteriores.

---

## 8. Regra de composição

Cada peça deve responder visualmente:

**O que é? → Do que é feito? → Como se organiza? → Como funciona? → Por que importa?**

A densidade visual deve servir à compreensão.

Evitar:

- decoração sem função cognitiva;
- excesso de cards;
- texto corrido;
- ícones sem significado;
- cores sem semântica;
- diagramas que sugerem causalidade inexistente;
- falsa precisão;
- elementos puramente ornamentais.

---

## 9. Tipografia e contraste

Manter a hierarquia tipográfica estabelecida pelo Visual Identity System principal.

Prioridades:

1. título;
2. subtítulo;
3. conceitos-chave;
4. relações/diagramas;
5. explicações;
6. fontes.

O contraste deve permanecer adequado à leitura em tela e impressão.

---

## 10. Princípio pedagógico

A Série A deve favorecer:

**VISÃO GERAL → ORGANIZAÇÃO → RELAÇÃO → INTEGRAÇÃO**

A cor, a composição e a hierarquia devem reduzir carga cognitiva desnecessária e facilitar a construção do modelo mental.

---

## 11. Regra de aprovação

Nenhum infográfico da Série A será considerado MASTER apenas por estar visualmente consistente.

Cada peça passa por:

1. especificação;
2. arquitetura visual;
3. produção;
4. auditoria científica;
5. auditoria visual;
6. microcorreções;
7. validação final;
8. incorporação ao catálogo/repositório.
